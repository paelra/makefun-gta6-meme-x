# GTA VI make.fun entry

This repository is the entry for the make.fun bounty `gta6-meme-x-01`. The meme was made to post on X from a public account with the text in [POST_TEXT.txt](POST_TEXT.txt). [POST.json](POST.json) will name the address of that post once it has been published.

Run the local handoff program with:

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
```
